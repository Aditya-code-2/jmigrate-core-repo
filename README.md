# jmigrate-core-repo1

[![](https://jitpack.io/v/Aditya-code-2/jmigrate-core-repo1.svg)](https://jitpack.io/#Aditya-code-2/jmigrate-core-repo1)

Custom Java database migration library for handling schema migrations smoothly.

---

## Installation (Maven)

Add both repository and dependency into your `pom.xml`:

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>[https://jitpack.io](https://jitpack.io)</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>com.github.Aditya-code-2</groupId>
        <artifactId>jmigrate-core-repo1</artifactId>
        <version>v.0.1</version>
    </dependency>
</dependencies>
